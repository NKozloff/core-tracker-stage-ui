# Core Tracker — Stage UI Overrides

Локальные визуальные переопределения интерфейса **Core Tracker Stage**. Файл `styles.css` — основной источник стилей для Chrome-расширения.

## Как работает синхронизация

Расширение содержит резервную копию CSS и при открытии / обновлении страницы `https://staging-control-center.white-rock.ae/` забирает актуальную версию:

`https://raw.githubusercontent.com/NKozloff/core-tracker-stage-ui/main/styles.css`

После изменения `styles.css` в этом репозитории достаточно обновить вкладку Stage. **Обновлять Chrome-расширение для каждой CSS-правки больше не требуется.**

## Первоначальная установка

Установите расширение **Core Tracker — Stage UI Overrides v07** (пакет передаётся в чате ChatGPT). В папке распакованного расширения должны находиться `manifest.json`, `background.js`, `content.js` и `стили.css`. Если установлена более старая версия, замените эти файлы и один раз нажмите Reload на странице `chrome://extensions`.

## Ограничения

- Автоматически синхронизируется только **CSS**. Для изменений JS или `manifest.json` понадобится обновить локальные файлы расширения.
- Для синхронизации требуется соединение с GitHub; при недоступности GitHub действует встроенный CSS.
- Репозиторий **публичный**. Не размещайте здесь данные аккаунтов, ключи, токены, cookies или приватный исходный код Stage.
- Это только визуальные изменения в браузере, а не изменение исходного приложения или API.
