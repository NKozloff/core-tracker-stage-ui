# CORE Stage — Approvals All by default

Дополнительное мини-расширение для Chrome. При открытии страницы `/financial-approvals` автоматически нажимает **существующий** таб **All** в интерфейсе платформы, даже если основной CSS скрывает табы.

## Установка

1. Скачайте ZIP-архив мини-расширения из чата и распакуйте его в постоянную папку.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку `core_approvals_auto_all`.
4. Обновите вкладку Stage.

Это отдельное дополнение к существующему расширению CORE UI Overrides: последнее продолжает загружать стили из `styles.css`. Простой коммит JavaScript в GitHub не устанавливает код автоматически в браузер.

После установки по умолчанию показываются настоящие данные вкладки **All**, включая список, сумму и количество заявок. Нарисованный в CSS переключатель **Only pending approval** остаётся визуально выключенным. Дополнение не меняет исходные записи на сервере.

Для отключения удалите дополнительное расширение в `chrome://extensions`.
